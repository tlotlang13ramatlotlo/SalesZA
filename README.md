# SalesZA

A mobile-friendly South African grocery price comparison prototype.

## Run locally

Open `index.html` in a browser. The prototype uses plain HTML, CSS, and JavaScript and requires no build tools.

## Price data

Product prices in this prototype are illustrative sample data. They are not live retailer prices and are not scraped from retailer websites. A production real-time comparison requires an authorized retailer API, partner feed, or licensed data provider; retailer, product, and location coverage will depend on that source.
